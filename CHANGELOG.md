# Change log

## 2026-10-11

- Expanded the archive from 153 to 168 studies, adding five works in each of inverse problems, inverse design, and PDE control.
- Added 45 verified author-associated code links to existing and new studies. Retained verification dates and primary-source provenance in the method index.
- Added Code and Collection filters, a recent-addition sorting option, and code links in cards and detail dialogs.
- Separated companion additions from the manuscript index. Counts and update dates now follow the data automatically.
- Preserved 30 literature-reported quantitative records, seven comparison protocols, and ten applicability workflows.
- Retained the second website design, official Zhejiang University emblem, and shared page-view counter.

Code links are not reproducibility certifications. One author-listed repository was unavailable at verification and has no active Code button. A second unavailable link was replaced with the first author’s current repository. A missing link does not establish that code is unavailable elsewhere.
